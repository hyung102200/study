# 원달러 환율 앱

1999년부터 현재까지의 원-달러 환율 데이터를 시각화하여 제공하는 웹 애플리케이션입니다.

## 기능

- **환율 차트 시각화**: 시계열 데이터를 라인 차트로 표시
- **시간 구간 선택**: 특정 기간의 환율 데이터만 조회 가능
- **툴팁 기능**: 마우스 호버 시 날짜와 환율 값 표시
- **반응형 디자인**: 데스크톱, 태블릿, 모바일 지원
- **0 값 필터링**: 공휴일 등의 데이터 누락 자동 처리

## 기술 스택

- **백엔드**: Node.js, Express.js
- **프론트엔드**: HTML, CSS, JavaScript
- **차트 라이브러리**: Chart.js
- **데이터 포맷**: CSV

## 설치 방법

1. 리포지토리 클론
```bash
git clone <repository-url>
cd tut02
```

2. 의존성 설치
```bash
npm install
```

## 실행 방법

1. 서버 시작
```bash
node server.js
```

2. 브라우저에서 접속
```
http://localhost:3000
```

## API 엔드포인트

### GET /api/data
전체 환율 데이터를 반환합니다.

**응답 예시:**
```json
[
  {
    "date": "1999-01-04",
    "rate": 1417.44
  },
  {
    "date": "1999-01-05",
    "rate": 1411.2
  }
]
```

### GET /api/data?start=YYYY-MM-DD&end=YYYY-MM-DD
특정 기간의 환율 데이터를 반환합니다.

**예시:**
```
GET /api/data?start=2000-01-01&end=2000-12-31
```

## 데이터 처리

- **빈 셀 처리**: 환율 값이 0인 경우 자동으로 제외
- **데이터 범위**: 1999-01-04부터 현재까지의 일별 환율 데이터
- **결측치 처리**: 공휴일 등으로 인한 데이터 누락은 자연스러운 간격으로 표시
